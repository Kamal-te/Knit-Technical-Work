INCTL Knitting Technical Work Monitoring

Impress Newtex Composite Textile Ltd

Start and stop timing for every technical job on the knitting floor, import the working sheet from Excel, and see how each technician, supervisor and executive is performing, daily, weekly or monthly.

Node.js 22.13+ SQLite, no install needed Works on computer and phone Role-based sign-in

What it does

Live job timer

Start a job when the technician begins and stop it when the work is finished. The start and end times are recorded automatically.

Machine and gauge

Pick the machine from the fixed list of 142 machines. Brand and dia fill in. The gauge is set per job.

Excel import

Upload the working sheet. Preview it first, then import. Re-importing the same file never duplicates jobs.

Performance dashboard

Standard versus actual time for each job, with extra and saved hours. Filter by day, week or month, technician, supervisor or executive.

Skill matrix

Each technician rated against each job family, from Expert to Developing. Gaps show where training is needed.

Machine view

Efficiency and extra time per machine, with the technicians who work on it. Machines are flagged for training when they fall below 85%.

Data checks

Flags jobs with a missing person, a start before the machine stopped, or no end time, so records can be corrected.

Standard names

Spelling variants of a person's name are changed to one standard name on every task, on import and on entry.

Who can do what

RoleCan do
AdminEverything: create and block users, change roles, manage people, import Excel, enter and edit tasks.
UserEnter and edit tasks, import Excel, view all reports.
ViewerView the performance dashboard and the task list. Cannot change anything.

Only email addresses an admin has created can sign in. Accounts start with a temporary password that the user changes at first sign-in.

Run it on your computer

cd technical-task-tracker
npm start

Then open http://localhost:3000. On a phone on the same Wi-Fi, open http://<this-computer-IP>:3000.

The first time, create the master admin in a separate terminal:

npm run create-admin

Other commands: npm test runs the test suite. npm run apply-roster updates an existing database to the current responsible list.
